# AquaVera

AquaVera, gri su ön arıtması için geliştirilen manyetik kitosan biyoboncuk prototipinin proje sitesidir.

## Siteyi açma

Bu depo GitHub Pages üzerinden yayımlanmak üzere hazırlanmıştır. Yerel kullanım için index.html dosyasını açın. Videoların çalışması için media klasörünü aynı dizinde tutun.

## Proje durumu

Çalışma okul laboratuvarında yürütülen bir ön çalışmadır. Gerçek gri suda güvenli yeniden kullanım henüz doğrulanmamıştır.
